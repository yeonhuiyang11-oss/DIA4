# 디아블로 IV 오버레이 (Diablo IV Overlay HUD)

윈도우 11 환경에서 디아블로 4를 즐기시는 분들을 위해 직접 만든 스마트 오버레이 프로그램입니다. 게임 화면 위에 띄워두고 아이템 드랍 정보나 보스 타이머, 그리고 빌드 사이트를 편하게 참고하실 수 있어요.

---

## 주요 기능

### 1. 실시간 아이템 및 드랍 테이블 검색
* 게임 중에 **Ctrl + F**를 누르면 언제든지 검색창이 툭 튀어나옵니다.
* 궁금한 아이템 이름이나 직업, 보스 이름을 입력하면 어떤 보스가 뭘 떨구는지 바로바로 확인할 수 있어요.
* 깃허브 서버와 연동되어 있어서 최신 데이터로 알아서 갱신되고, 인터넷이 안 될 때는 로컬 캐시로 안전하게 작동합니다.
* **💡 검색 팁:** 정확한 실제 아이템 이름으로 검색이 안 될 경우에는 **인검**처럼 입력하신 뒤 **스페이스바**나 **방향키 아래쪽**을 눌러보세요!

### 2. 실시간 월드 보스 타이머
* 오버레이 상단에 다음 월드 보스가 언제 나오는지 분/초 단위로 실시간 카운트다운을 보여줍니다.
* 깃허브 API를 통해 스케줄이 자동으로 싱크되니까 시간 놓칠 일 걱정 없어요.

### 3. 미니 웹 브라우저 (독립형 웹 오버레이)
* 게임 화면 밖으로 Alt+Tab 할 필요 없이 띄워두고 볼 수 있는 미니 브라우저입니다.
* 맥솔(Maxroll), 모발리티릭스(Mobalytics), 디아4 인벤 등 자주 쓰는 사이트들을 바로 열 수 있어요.
* **편의 기능:**
  * 주소 직접 입력 및 구글 검색 가능
  * 자주 가는 페이지 북마크 저장/삭제
  * 영문 사이트가 편해지는 구글 번역 기능 탑재
  * 화면 크기에 맞게 자유로운 확대/축소(Zoom) 지원

### 4. 내 입맛대로 맞추는 설정 화면
* 투명도 슬라이더로 게임 화면을 가리지 않게 투명하게 조절할 수 있습니다.
* 글자 크기, 보스 글자 크기, 창 크기까지 전부 내 스타일에 맞게 커스텀 가능해요.
* 텍스트 색상이랑 배경색도 컬러 피커로 예쁘게 바꿀 수 있습니다.
* 한 번 맞춰둔 위치랑 설정은 `config.json`에 알아서 저장되니까 껐다 켜도 그대로 유지됩니다.

---

## 다운로드 및 사용 방법

1. 어버레이 최종버전 폴더를 9개로 분할 압축한 파일들을 **모두 같은 폴더 안에** 받아주세요.
2. 첫 번째 압축 파일을 풀면 하나의 폴더로 깔끔하게 합쳐집니다.
3. 폴더 안에 있는 실행 파일을 켜서 바로 쓰시면 됩니다!
   * (최초 실행 시 보스 정보나 아이템 데이터를 가져오기 위해 인터넷 연결이 필요해요.)
