# 디아블로 IV 오버레이 (Diablo IV Overlay HUD)

윈도우 11 환경에서 디아블로 4를 즐기시는 분들을 위해 정성껏 만들어 본 스마트 오버레이 프로그램이에요. 게임 화면 위에 예쁘게 띄워두고 아이템 드랍 정보나 보스 타이머, 그리고 유용한 빌드 사이트들을 편하게 참고하실 수 있답니다. 💕

---

## 주요 기능

### 1. 실시간 아이템 및 드랍 테이블 검색
* 게임 중에 **Ctrl + F**를 누르면 언제든지 검색창이 가볍게 툭 튀어나와요.
* 궁금한 아이템 이름이나 직업, 보스 이름을 슥 입력하면 어떤 보스가 무엇을 주는 바로 확인할 수 있어요.
* 깃허브 서버와 연동되어 있어서 최신 데이터로 알아서 척척 업데이트되고, 혹시 인터넷이 안 될 때도 로컬 캐시로 안전하게 작동한답니다.
* **💡 검색 팁:** 정확한 실제 아이템 이름으로 검색이 잘 안 될 때에는 **인검**처럼 간단히 입력하신 뒤, **스페이스바**나 **방향키 아래쪽**을 톡톡 눌러보세요!

### 2. 실시간 월드 보스 타이머
* 오버레이 상단에 다음 월드 보스가 언제 등장하는지 분과 초 단위로 다정하게 카운트다운을 보여드려요.
* 깃허브 API를 통해 스케줄이 자동으로 척척 싱크되니까 소중한 보스 타임을 놓칠 걱정은 전혀 없어요.

### 3. 미니 웹 브라우저 (독립형 웹 오버레이)
* 게임 화면 밖으로 번거롭게 Alt+Tab 하실 필요 없이, 화면에 띄워두고 곁눈질로 볼 수 있는 미니 브라우저예요.
* 맥솔(Maxroll), 모발리티릭스(Mobalytics), 디아4 인벤 등 자주 찾는 유용한 사이트들을 원클릭으로 바로 열 수 있어요.
* **편리한 기능들:**
  * 주소 직접 입력 및 구글 검색 가능
  * 자주 가는 소중한 페이지 북마크 저장 및 삭제
  * 영문 사이트도 편안하게 읽을 수 있는 구글 번역 기능 쏙 탑재
  * 화면 크기에 맞춰 자유자재로 조절하는 확대/축소(Zoom) 지원

### 4. 내 취향 가득 담는 설정 화면
* 투명도 슬라이더로 게임 화면을 방해하지 않도록 나만의 알맞은 투명도로 조절할 수 있어요.
* 글자 크기, 보스 글자 크기, 창 크기까지 전부 내 스타일에 찰떡같이 커스텀 가능하답니다.
* 예쁜 텍스트 색상과 배경색도 컬러 피커로 손쉽게 콕콕 바꿔보세요.
* 한 번 예쁘게 맞춰둔 위치와 설정들은 `config.json`에 척척 저장되니까, 다음에 껐다 켜도 그 모습 그대로 유지돼요.

---

## 다운로드 및 사용 방법

1. 오버레이 최종버전 폴더를 9개로 분할 압축한 파일들을 **모두 같은 폴더 안에** 쏙 넣어주세요.
2. 첫 번째 압축 파일을 부드럽게 풀어주시면 하나의 폴더로 깔끔하게 합쳐진답니다.
3. 폴더 안에 있는 실행 파일을 켜서 즐겁게 사용해 주시면 돼요!
   * (최초 실행 시 보스 정보나 아이템 데이터를 예쁘게 가져오기 위해 인터넷 연결이 살짝 필요해요.)
